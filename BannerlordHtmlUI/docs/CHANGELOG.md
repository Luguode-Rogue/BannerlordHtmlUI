## 如何使用

- 想知道“现在怎么用”：看 `README.md`、`DEVELOPMENT_GUIDE.md`、`API.md`。
- 想知道“为什么现在这样”：看 `BUG_KNOWLEDGE_BASE.md` 和 Handoff Postmortem / Bugfix。
- 想知道“某个版本改了什么”：直接进入对应 `CHANGELOG_v*.md`。
- 想知道“当前尚未验收什么”：看 `PROJECT_STATUS.md` 与 `V0.44_RELEASE_CHECKLIST.md`。

## 文档治理规则

未来版本：

1. 先以 `.csproj` 的 `<Version>` 作为工程版本事实来源。
2. 在本索引增加当前版本条目。
3. 创建对应版本变更记录。
4. 不把版本变更、Bug 复盘、当前状态写进同一份文档。
5. 既有历史记录只归档，不改写成当前规范。
