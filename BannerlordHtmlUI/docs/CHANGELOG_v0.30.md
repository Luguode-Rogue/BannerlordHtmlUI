# v0.30

- Added frontend DOM state binding without a frontend framework dependency.
- Added `game.bind` and consumer-scoped `game.app.bind` helpers.
- Added text, value, checked, disabled, and attribute bindings.
- Added declarative `data-bhui-*` attributes.
- Added binding disposal/unsubscribe support.
- Binding is intentionally one-way; C# remains the authoritative game-state source.
- Added runtime binding regression test and frontend binding documentation.
